# Sudoku 🧩

Proyecto de **Sudoku desarrollado en Python** como ejercicio práctico de programación.

## 📌 Descripción

El proyecto consiste en crear un programa capaz de trabajar con un tablero de Sudoku de **9x9**, siguiendo las reglas habituales del juego.

El objetivo es practicar conceptos de programación como:

* Variables y tipos de datos
* Listas y matrices
* Funciones
* Bucles
* Condicionales
* Comprobación de datos
* Lógica de programación

## 🎮 Reglas del Sudoku

El objetivo es completar el tablero utilizando los números del **1 al 9**.

Cada número debe aparecer una sola vez en:

* Cada fila
* Cada columna
* Cada bloque de 3x3

## 🐍 Requisitos

Para ejecutar el proyecto es necesario tener instalado **Python 3**.

Puedes comprobar la versión con:

```bash
python --version
```

## ▶️ Ejecución

Desde Git Bash, entra en la carpeta del proyecto:

```bash
cd /c/PYTHON/Sudoku
```

Después ejecuta el programa:

```bash
python sudoku.py
```

## 🎯 Objetivo

Este proyecto se ha realizado como práctica para mejorar los conocimientos de **programación en Python** y aplicar la lógica necesaria para trabajar con un Sudoku.
